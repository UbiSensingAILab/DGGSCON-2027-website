# Website conventions

- This repository is public. Add only approved public-facing website content. Keep internal meeting notes, financial planning, draft governance documents, personal assessments and credentials in the private planning repository.
- Publish only `docs/` through GitHub Pages. Keep maintenance instructions at the repository root.
- Use lowercase, hyphen-separated filenames for new files; retain conventional `README.md` and `AGENTS.md` names.
- This is a buildless static site. Prefer semantic HTML, CSS and minimal JavaScript; do not add a framework or dependencies without a concrete need.
- Keep asset paths relative so the site works at the GitHub Pages project URL and on a future custom domain.
- Mark provisional conference details clearly. Do not invent confirmed speakers, sponsors, institutional endorsements, publication/indexing arrangements, submission deadlines or prices.
- Respect keyboard access, visible focus, readable contrast, responsive layouts and reduced-motion preferences.
- Validate local links and inspect desktop and mobile layouts before publishing changes.
